# Safe Space ♡ (พื้นที่สบายใจ)

> "A little place to come back to yourself."  
> พื้นที่สบายใจสำหรับบันทึกความรู้สึก อารมณ์ และช่วงเวลาดีๆ ของคุณ สไตล์ **Cute Digital Diary × Pinterest Scrapbook**

---

## 🎀 ภาพรวมของโปรเจกต์ (Features)

### 📖 Phase 1 & 2: Daily Journal & Mood Tracker
- **Journal**: บันทึกเรื่องราว ความรู้สึก ใส่รูปภาพ เพลง และแท็ก
- **Mood Tracker**: เช็คอินอารมณ์ประจำวัน บันทึกโน้ตสั้นๆ
- **Calendar**: ปฏิทินแสดงบันทึกและอารมณ์ในแต่ละวัน
- **Memories**: แกลเลอรีรูปภาพสไตล์โพลารอยด์ (Polaroid Scrapbook)
- **Scrapbook Themes**: รองรับ 7 ธีมสี (Pink Polka, Baby Blue, Lavender, Pistachio, Strawberry, Cocoa, Midnight)

### ✨ Phase 3: Little Treasures
- **💌 Letters (Dear Future Me)**: เขียนจดหมายถึงตัวเองในอนาคต พร้อมระบบตั้งเวลาปลดล็อก
- **🌱 My Little Garden**: สวนดอกไม้จำลองที่เติบโตตามการดูแลตัวเอง พร้อมระบบ Streak Tracker
- **📊 My Year Recap**: สรุปภาพรวมอารมณ์และสถิติทั้งปี พร้อม Donut Chart และ Activity Heatmap
- **⚙️ Settings**: ปรับแต่งชื่อเล่น (Nickname), ฟอนต์ (ปกติ / ลายมือ / คลีน), สำรองและกู้คืนข้อมูล (JSON Export/Import)

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5**
- **CSS3** (Custom Properties / CSS Variables, Flexbox, Grid, Keyframe Animations)
- **Vanilla JavaScript** (LocalStorage API, Blob Download API, Event Delegation)
- ไม่มี Dependency ภายนอก (No frameworks, No build tools needed)

---

## 🚀 วิธีเปิดใช้งาน (Getting Started)
สามารถเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Chrome, Edge, Safari, Firefox) เพื่อเริ่มใช้งานได้ทันที
